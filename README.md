# PlayTo_KS4036

> A repository for experimenting with the KS4036.

The aim of this repository is to document the **inputs and outputs of the KS4036** so you can experiment and play with the board.

You can interact with the KS4036 in several ways:

* Using **Python UDP** and **MakeCode blocks** with Gomi.
* Using a **Godot simulation** of the KS4036.

Related repositories:

* https://github.com/EloiStree/HelloTwoWheelsCarKS4036
* https://github.com/EloiStree/2026_09_11_python_micro_bit_hub
* https://github.com/EloiStree/2026_09_12_makecode_hello_uart_bluetooth_ks_4036

## Inputs and Outputs

The exact input/output mapping may change between implementations, but the underlying logic remains the same.

The KS4036 provides:

* 2-line reader
* 2 LEDs
* 2 motors
* 1 ultrasonic sensor
* 2 light-dependent resistors (LDRs)
* Micro:bit sensors
