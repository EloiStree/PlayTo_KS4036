# PlayTo_KS4036

> Allows to play with KS4036


- https://github.com/EloiStree/HelloTwoWheelsCarKS4036
- https://github.com/EloiStree/2026_09_11_python_micro_bit_hub
- https://github.com/EloiStree/2026_09_12_makecode_hello_uart_bluetooth_ks_4036


Input can change from one code to and other.
But the logic of the input stay the same.

- 2 line reader 
- 2 read led
- 2 motors
- 1 sonic sensor
- 2 light resistance
- micro:bit sensor.
